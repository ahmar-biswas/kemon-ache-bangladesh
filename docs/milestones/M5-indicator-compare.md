## Skills
dataviz.

## Steps
1. Build `/indicator/<id>` as specified in section 12: headline, Bangladesh trend, peer comparison over time, latest-year comparison, scatter against income where it makes sense, table, CSV, how to read, and the source box.
2. Build the country picker with the default peers, presets, search, and the "Why these countries?" note. Peers with no recent data are omitted with a visible note.
3. Build `/compare` using the same module with an indicator picker.
4. Every chart: Chart | Table switch, CSV, direct labels, tooltip, source line with the selected countries in the link where the source supports it.

## Done when
- Any P0 indicator works end to end in both languages.
- Adding or removing countries updates charts, tables, CSV and source links.

## Then
Run tests, update docs/PROGRESS.md, commit, and stop. Report: what was built, three things for the user to check by eye, anything unresolved.
