## Skills

## Steps
1. Set up free hosting (GitHub Pages or Cloudflare Pages) and give the owner exact click-by-click steps for anything that needs the owner’s account.
2. Enable the weekly refresh workflow with validation, last-good-data fallback and the visible Last checked and Latest data year notices.
3. Run a full refresh in the real environment and confirm nothing unvalidated is published.
4. Write the README: how it works, how to add an indicator, how to update the Bangla text, what to do if a refresh fails.

## Done when
- The site is live in both languages.
- A scheduled refresh has run successfully once.

## Then
Run tests, update docs/PROGRESS.md, commit, and stop. Report: what was built, three things for the user to check by eye, anything unresolved.
